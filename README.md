# animesh-chouhan.github.io

The profile homepage and blog repository of Animesh Singh. <https://animeshchouhan.com/>

Built with [Astro](https://astro.build). Posts and projects are Markdown files in `src/content/`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

Pushing to `master` builds the site and deploys it to GitHub Pages (`.github/workflows/deploy.yml`).
